Inter-Thread Communication Chaos Matrix

Measures round-trip throughput between main thread and Web Worker(s) under increasing concurrency. Simulates the worst-case anti-pattern: N independent code modules all firing uncoordinated bidirectional messages. Each round-trip modifies data on both sides.

Approaches: Structured Clone · Transferable · MessageChannel (1:1) · SAB + postMessage · SAB + Atomics · Comlink Proxy · Dedicated Worker Pool · Transferable Streams · IndexedDB · Web Locks

Fast (>10k rt/s) Moderate (1k–10k rt/s) Slow (<1k rt/s) N/A (not supported or failed)

Methodology

  • Round-trip = main sends data → worker modifies → worker replies → main receives.
  • Sequential (concurrency=1): one caller awaits each round-trip before starting the next.
  • Chaos (concurrency=N): N independent loops each fire round-trips as fast as possible for the duration.
  • Pre-allocation: All payloads/buffers are created once during setup() as zero-initialized and reused across round-trips. No filling happens on the hot path. The measured cost is only message-passing + worker-side modification.
  • 1 KB payload: object with a 1 KB Uint8Array; worker touches every byte.
  • 1 MB payload: object with a 1 MB Uint8Array; worker touches header + 16 samples.
  • 10 MB payload: object with a 10 MB Uint8Array; worker touches header + 16 samples. This is where transferable zero-copy should dominate structured clone.
  • Comlink Proxy: Simulated RPC via MessageChannel — method call serialized as {method,args,id}, response proxied back.
  • Dedicated Worker Pool: Spawns exactly concurrency workers, each serving exactly one caller.
  • Transferable Streams: One TransformStream pair per caller, all piped through a single worker. Tests per-pipe overhead and backpressure isolation.
  • IndexedDB: Worker writes payload to IDB, reads it back. Tests persistence layer round-trip cost.
  • Web Locks: Main acquires shared lock, worker acquires shared lock, both modify shared state, both release. Tests coordination overhead.
  • SAB requires cross-origin isolation headers — shown as N/A if unavailable.
