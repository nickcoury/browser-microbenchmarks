DOM Manipulation

Compares four common ways to insert multiple elements into the DOM: innerHTML (string concat), createElement (imperative API), DocumentFragment (batch insert), and insertAdjacentHTML (string append). Each variant inserts 100 <div> nodes into a detached container so layout cost is isolated.
